# Week 4 Assignment Deliverable

## Stack Rationale

**Chosen Stack:** Next.js (React Framework) with Tailwind CSS, hosted on Vercel.

**Alternatives Considered:**
1. *No-Code (Carrd / Framer):* While extremely fast to publish, I rejected this because I am applying for frontend engineering roles. Dragging and dropping a layout does not serve as proof of my technical ability to write maintainable code or handle web architecture.
2. *Plain Code + AI (HTML/CSS on Netlify):* I heavily considered this because it is the cleanest, simplest approach. However, I rejected it because as my portfolio grows to include multiple case studies, maintaining duplicate HTML headers and navbars across several pages manually becomes tedious. 

**Why I Chose Next.js (And Can I Maintain It?):**
I chose Next.js because my work needs to be displayed as a developer. Using a React framework allows me to easily componentize my UI (like the header and footer) and eventually embed interactive, live React components directly into my case studies. 

While a framework is often overkill for a simple portfolio, **I can maintain this** because I already have it set up cleanly, the code is fully version-controlled in GitHub, and Vercel handles the deployment pipeline automatically every time I push. The repository itself acts as the first piece of proof of my engineering abilities.
